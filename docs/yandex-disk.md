# Прежняя выгрузка на Яндекс Диск

Автоматическая замена XLSX отключена. Заявки добавляются строками в динамическую таблицу Яндекс Вики. Ранее загруженный XLSX остаётся на Диске; токен и переменные `YANDEX_DISK_*` больше не используются приложением.

Актуальная настройка — в [инструкции Яндекс Вики](yandex-wiki.md). Excel по-прежнему можно скачать из админки сайта.
